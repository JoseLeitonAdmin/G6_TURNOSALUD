## Descripción General

Este repositorio contiene la planificación y documentación administrativa para el desarrollo de **«TurnoSalud»**, una plataforma web diseñada para que una clínica privada pueda gestionar y agendar las citas médicas de sus pacientes de forma ordenada y eficiente.

El trabajo sigue las buenas prácticas de organización de proyectos para pequeñas empresas (norma internacional ISO/IEC 29110), asegurando que el sistema se entregue en un plazo de **12 semanas**, dentro de un presupuesto de **US$ 18 000** y cumpliendo con todos los acuerdos establecidos con la clínica.
